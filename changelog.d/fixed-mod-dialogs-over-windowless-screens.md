Buttons that open a mod's own window from one of our full-screen readers now hand that window the keyboard. Vanilla Factions Expanded - Tribals' Cornerstones button on the Factions screen was the clearest case: the window opened and read itself out, but every key after that still went to the faction list behind it, so the screen had to be closed before the window would answer. This affected any mod window that does not declare itself a modal dialog, and it is fixed for every screen at once rather than per mod.
